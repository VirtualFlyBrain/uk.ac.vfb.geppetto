# VFB Geppetto Data Sources

> **Retired (November 2026).** This repository is archived and no longer developed.
> The Virtual Fly Brain viewer (geppetto-vfb) is now a static web app with no Java
> backend, so these data sources are not built or deployed. Term info and queries
> now come from [VFBquery](https://github.com/VirtualFlyBrain/VFBquery). The last
> deployed code is on the `v2.2.5.4` branch.
